# osu! replay critique — report template

This is the generic critique structure used by `osu-critique report` (deterministic,
no LLM) and expanded by `osu-critique coach` (LLM, BYO key). Field names map to the
metrics JSON produced by `osu-critique analyze` (see `examples/sample_metrics.json`).

---

## 2. Timing

- Hit error: mean `{{ mean_err }}ms` (early/late bias: `{{ early_pct }}%` early), std `{{ std_err }}ms` → UR `{{ ur }}`
- OD windows: 300 = ±`{{ w300 }}`ms, 100 = ±`{{ w100 }}`ms
- Interpretation thresholds (vs baseline if provided):
  - UR < 120 → excellent · 120–180 → good · 180–250 → inconsistent · > 250 → timing breakdown
  - |mean_err| > 6ms with consistent sign → offset/bias worth investigating

## 3. Aim

- Mean aim error `{{ aim_mean_norm }}r` (circle radii), p90 `{{ aim_p90_norm }}r`
- Interpretation: < 0.30r strong · 0.30–0.45r good · 0.45–0.60r acceptable · > 0.60r aim struggling

## 5. Streams

- `{{ n_stream_segments }}` segments, `{{ stream_objects }}` objects, `{{ stream_misses }}` misses
- Longest segments + their per-segment std (UR) and alternation ratio:
  `{{ segments_summary }}`
- Segment std > 30ms or alternation ratio < 90% → rhythm collapse under sustained tapping.

## 6. Sections & fatigue

- Quarter breakdown: Q1–Q4 (miss / mean_err / std)
- Misses clustering in one quarter → section-specific difficulty; degrading std toward
  Q4 → fatigue.

## 7. Tapping

- Alternation ratio `{{ alt_ratio }}` (good > 90%), same-key adjacencies `{{ same_key_pct }}`
- Key balance A/B `{{ keys }}`
- Whiffed presses `{{ whiffs }}` (rate `{{ whiff_rate }}` of presses) — whiff rate > 10%
  indicates rushing / tapping before the cursor lands.

## 8. Practice recommendations (ranked)

1. Highest-leverage target derived from the pattern/section with the worst miss rate
   vs its timing std (e.g. dense-pattern placement drills, UR reduction, whiff discipline).
2. Second target from timing bias (offset test if consistent sign) or stream segments.
3. Endurance/stamina only if quarter/std degradation is present; otherwise note that
   long-map failure is section-driven.
